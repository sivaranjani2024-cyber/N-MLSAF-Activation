# N-MLSAF-Activation
Python implementation of N-degree Mittag-Leffler Sigmoidal Activation Function

## Files
- `mlsaf.py`: Implementation of the N-MLSAF activation function.
- `lenet_mnist_demo.py`: Example training script with LeNet + MNIST.
- `requirements.txt`: Dependencies.

## How to Run
```bash
pip install -r requirements.txt
python lenet_mnist_demo.py
